How this was checked

From a fresh worktree: npm install, npm run build:shared, npm run db:generate, then npm run typecheck, npm run lint and npm test. The compose stack was rebuilt with npm run start and the integration, browser, load and audit tiers were run against it. Two browser contexts, one booking and the other watching, were driven by Playwright rather than by hand.
